# Kedi Klavyeye Oturan Kod

## Bu Ne?

Bu, tarihin en absürt GitHub reposudur. Bir kedinin klavyenin üstüne oturarak yazdığı kod. 

Evet, gerçekten. Kedi oturdu, tuşlara bastı, ve bu çıktı.

Ama bir şekilde çalışıyor. İnanmıyor musun? Çalıştır ve gör.

## Nasıl Çalıştırılır?

```bash
python kedi_kodu.py
```

Bu kadar. Kedi matematiği, miyav çevirisi, klavye saldırısı simülasyonu. Hepsi burada.

## Özellikler

- **Kedi Matematiği**: 2+2 bazen 4, bazen 7, bazen -1. Kedi bilir.
- **Miyav Çevirici**: İnsan dilini kedi diline çevirir. Bilimsel olarak kanıtlanmış değil ama eğlenceli.
- **Klavye Saldırısı**: Kedinin rastgele tuşlara basmasını simüle eder.
- **Abartılı Ciddiyet**: Bu kodu NASA kullanabilir. Kullanmaz ama kullanabilir.

## Neden Bu Repo?

Çünkü dünya yeterince ciddi. Bir kedi otursun klavyeye, kod yazsın. 

Bu, yapay zekanın (ve kedilerin) geleceğidir.
